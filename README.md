# Cadastro de Produtos e Clientes

Estrutura inicial de um sistema para cadastro e organização de **produtos** e **clientes**.

## Estrutura do projeto

```text
cadastro-produtos-clientes/
├── src/
│   ├── main.py
│   ├── clientes/
│   └── produtos/
├── tests/
├── docs/
├── assets/
├── config/
├── data/
├── .env.example
├── .gitignore
├── README.md
└── requirements.txt
```

## Tecnologias

- Python 3
- Organização modular com código em `src/`
- Testes separados em `tests/`

## Como executar

A implementação será adicionada nas próximas etapas. O ponto de entrada previsto é `src/main.py`.

## Segurança

Variáveis de ambiente e credenciais devem ser mantidas em um arquivo `.env` local. Nunca versionar chaves, senhas ou dados sensíveis.
